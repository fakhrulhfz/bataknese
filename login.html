Pilih Peran Login: User, Operator, atau Admin

Klik tombol Isi Form untuk menyalin kredensial ke formulir login, atau klik Login Cepat untuk langsung masuk dan menguji pembatasan akses Halaman Dashboard.

Aturan Hak Akses Sistem:
• User: Hanya dapat mengakses Halaman Utama Aplikasi (Stok Kulkas, Resep, Meal Plan, Belanja). Akses ke Halaman Dashboard ditolak otomatis.
• Operator: Dapat mengakses Halaman Dashboard (CRUD Stok, Resep, UMKM, Paket Meal Plan & Verifikasi Halal) serta Halaman Utama.
• Admin: Akses penuh Halaman Dashboard + Manajemen Akun Dummy, Log Login & Reset Sistem.
